# AI TRPG 핵심 상호작용 흐름 - 시나리오 2 (v1.3)

## 1. 개요

본 문서는 플레이어의 행동이 세상에 미치는 영향을 시뮬레이션하는 **고급 과정**을 정의합니다. 이 설계는 **'결과의 불확실성'** 과 **'지속적으로 살아 움직이는 세계'** 를 구현하는 데 중점을 둡니다.

핵심 개선점:
*   **조건부 이벤트 (Conditional Events):** 예약된 미래가 플레이어의 후속 행동에 따라 변경될 수 있습니다.
*   **월드 클럭 (World Clock):** 플레이어의 휴식과 무관하게 세상의 시간이 흐릅니다.
*   **보고된 사실 vs. 그라운드 트루스:** 시스템은 정보의 불확실성을 인지하고 서사에 활용합니다.
*   **이벤트 우선순위:** 시스템은 이벤트 간의 충돌을 지능적으로 해결합니다.

## 2. 시나리오 2: 모험을 마친 뒤 거점으로 귀환하기 (개선안 v1.3)

*   **플레이어 목표**: "방금 끝낸 모험의 결과를 세상이 어떻게 인식하는지 보고 싶다."
*   **시작 상태**: 플레이어는 모험의 마지막 단계를 막 완료했습니다. `월드 클럭`은 계속해서 시간을 추적하고 있습니다.

---

### [흐름 1] 불완전한 사실 보고 및 검증

1.  **`⚔️ 던전 마스터`**:
    *   **Process**: 모험 완료를 확인하고, 자신이 **관찰한 범위 내에서** 구조화된 보고서를 생성합니다.
    *   **Output (to `⚙️ 오케스트레이터`)**: `ReportedFact` 객체를 제출합니다. 이 보고서는 '진실'이 아닌, '던전 마스터의 관점에서 본 사실'임을 명시합니다.
        ```json
        {
          "event": "adventure_completed",
          "reporter": "dungeon_master_7",
          "reported_facts": {
            "adventure_id": "stolen_pie",
            "key_facts": ["Thieves were orphans", "Player paid the shopkeeper"],
            "solution_type": "merciful"
          }
        }
        ```

2.  **→ `📜 서사 엔진`**:
    *   **Input**: `ReportedFact` 객체.
    *   **Process**:
        1.  보고된 사실을 분석합니다.
        2.  **정보의 불확실성을 인지합니다.** ('플레이어가 돈을 냈지만, 그 돈이 고아들에게 정말 전달되었는지는 알 수 없음').
        3.  이 불확실성을 바탕으로, **검증 이벤트**를 포함한 조건부 이벤트들을 생성합니다.
    *   **Output (to `📚 데이터 저장소`)**: `timed_event_queue`에 **조건과 우선순위가 포함된** 이벤트들을 기록합니다.
        ```json
        {
          "timed_event_queue": [
            {
              "event_id": "evt_rumor_mercy_1",
              "type": "rumor_spread",
              "details": "자비로운 모험가에 대한 소문",
              "delay": "1_day",
              "priority": 5,
              "conditions": ["player_criminal_record < 1", "is_debt_truly_paid == true"]
            },
            {
              "event_id": "evt_verify_debt_1",
              "type": "internal_verification",
              "details": "고아들의 빚이 실제로 해결되었는지 확인",
              "delay": "2_days",
              "priority": 3
            },
            {
              "event_id": "evt_guards_neg_rep_1",
              "type": "reputation_update",
              "faction": "town_guards", "change": -1,
              "delay": "2_days",
              "priority": 5,
              "conditions": ["player_criminal_record < 1"]
            }
          ]
        }
        ```

### [흐름 2] 월드 클럭과 지속적인 이벤트 처리

1.  **`⚙️ 오케스트레이터`**: 마스터를 `거점 마스터`로 전환하고, 플레이어는 마을로 귀환합니다.
2.  **`⏰ 월드 클럭`**: 플레이어가 마을을 돌아다니며 다른 활동을 하는 동안에도, `월드 클럭`은 계속해서 **'틱(Tick)'**을 발생시킵니다.
3.  **`📜 서사 엔진`**:
    *   **Input**: `월드 클럭`의 `tick` 이벤트.
    *   **Process**: 매 틱마다 `timed_event_queue`를 확인합니다. `delay`가 만료된 이벤트들의 **'조건'**을 현재 `월드 상태`에 비추어 재평가합니다.
        *   **만약 플레이어가 그 사이 범죄를 저질렀다면?** `player_criminal_record < 1` 조건이 실패합니다. `evt_rumor_mercy_1` 이벤트는 "위선적인 모험가에 대한 소문"으로 내용이 **수정**되거나 **취소**될 수 있습니다.
        *   **`evt_verify_debt_1` 이벤트가 처리될 시간이 되면?** 시스템은 빵집 주인의 정직도, 고아들의 상태 등을 `그라운드 트루스`와 대조하여 `is_debt_truly_paid` 라는 새로운 월드 상태 변수를 `true` 또는 `false`로 확정합니다.
    *   **Output**: 조건이 충족된 이벤트만 최종적으로 처리하여 `데이터 저장소`의 `월드 상태`와 `캐릭터 상태`를 업데이트합니다.

---

### [흐름 3] 이벤트 충돌 해결

*   **`📜 서사 엔진`**:
    *   **Scenario**: 큐를 처리하는 도중, 'NPC 밥이 마을을 떠남'(우선순위 9) 이벤트와 'NPC 밥이 길드장이 됨'(우선순위 6) 이벤트가 동시에 처리될 시간이 되었다고 가정합니다.
    *   **Process (Conflict Resolution)**:
        1.  두 이벤트의 대상이 'NPC 밥'으로 동일함을 확인하고 충돌을 인지합니다.
        2.  **충돌 해결 규칙**에 따라, `priority`가 더 높은 'NPC 밥이 마을을 떠남' 이벤트를 먼저 처리합니다.
        3.  'NPC 밥이 마을을 떠남' 이벤트가 성공적으로 처리되면, 이제 'NPC 밥'은 마을에 존재하지 않으므로 'NPC 밥이 길드장이 됨' 이벤트의 암묵적 조건(NPC가 마을에 있어야 함)이 깨졌다고 판단합니다.
    *   **Output**: 'NPC 밥이 길드장이 됨' 이벤트를 **자동으로 취소**하고, 충돌이 해결되었음을 기록합니다.

### [흐름 4] 결과 확인 및 입체적인 서사

1.  **Player Action**: 며칠 뒤, "고아들은 잘 지내나?"라며 고아들을 찾아갑니다.
2.  **`🏡 거점 마스터` → `📜 서사 엔진`**: `get_narrative_context`를 호출합니다.
3.  **`📜 서사 엔진`**:
    *   **Process**: 그동안 `월드 클럭`의 틱과 이벤트 처리를 통해 **모든 조건부/충돌 이벤트가 해결된 최종적인 `월드 상태`**를 `데이터 저장소`에서 가져옵니다.
        *   **만약 빵집 주인이 정직했다면:** "고아들은 빚을 갚고 새 삶을 살고 있으며, 당신을 은인으로 여긴다"는 긍정적 결과를 도출합니다.
        *   **만약 빵집 주인이 사기꾼이었다면:** "고아들은 여전히 빚에 쪼들리고 있으며, 당신의 도움이 헛수고가 되었다는 사실"과 함께 "사기꾼 빵집 주인에 대한 새로운 퀘스트"를 제안할 수 있습니다.
    *   **Output (to `🏡 거점 마스터`)**: 이처럼, 플레이어의 초기 행동과 그 후의 월드 시뮬레이션이 상호작용하여 만들어진, 예측 불가능하고 입체적인 결과를 연출 가이드로 전달합니다.
