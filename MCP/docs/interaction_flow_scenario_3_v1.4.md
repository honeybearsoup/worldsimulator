# AI TRPG 핵심 상호작용 흐름 - 시나리오 3 (v1.4 최종안)

## 1. 개요

본 문서는 **LLM 기반의 전문 마스터(AI Master)**가 어떻게 풍부한 데이터 컨텍스트를 활용하여, 플레이어와 깊이 있는 관계를 형성하고 개인적인 서사를 자연스럽게 이끌어내는지를 정의합니다.

핵심 철학은 **'LLM에게 최고의 재료를 제공하는 것'**입니다. 시스템은 복잡한 논리 분기를 하드코딩하는 대신, 각 상황에 대한 다각적인 데이터를 구조화하여 LLM 마스터가 창의적이고 지능적인 판단을 내릴 수 있는 기반을 마련하는 데 집중합니다.

## 2. 시나리오 3: 중요 NPC와의 관계 발전 (v1.4)

*   **플레이어 목표:** "빵집 주인 '홀리'와 더 깊은 이야기를 나누고 싶다."
*   **핵심 데이터 객체:**
    *   `StoryHook`: 특정 서사로 이어지는 여러 '진입점'을 정의한 데이터.
    *   `RelationshipState`: NPC와의 관계를 다차원적으로 표현하는 데이터.

---

### [흐름 1] 다중 채널 힌트와 LLM의 서사적 암시

1.  **`📚 데이터 저장소`**: `서사 엔진`에 의해 다음과 같은 `StoryHook` 데이터가 미리 생성되어 있습니다. LLM 마스터는 이 정보를 보고 어떤 힌트를 줄지 결정합니다.
    ```json
    {
      "hook_id": "holly_brother_story",
      "urgency": "low",
      "triggers": [
        { "source_type": "conversation", "target_npc_id": "holly_baker", "keywords": ["숲", "가족", "걱정"] },
        { "source_type": "rumor", "location": "tavern", "rumor_id": "rumor_holly_sad" },
        { "source_type": "item_discovery", "location": "holly_bakery", "item_id": "faded_drawing" }
      ]
    }
    ```
2.  **Player Action**: "홀리에게 다가가 안부를 묻는다."
3.  **`🏡 거점 마스터 (LLM)`**:
    *   **Input**: `get_narrative_context`를 통해 현재 상황과 관련된 `StoryHook` 목록을 JSON으로 받습니다.
    *   **LLM Process**:
        1.  단순한 안부 인사지만, `holly_brother_story`라는 중요한 훅이 존재함을 인지합니다.
        2.  이 훅을 플레이어에게 강요하지 않으면서도, 자연스럽게 암시할 수 있는 묘사를 **창의적으로 생성**합니다.
    *   **Output (to Player)**: "홀리가 당신을 보고 환하게 웃으며 반겨줍니다. '덕분에 걱정 없이 지내고 있어요, 정말 고마워요.' 그녀는 잠시 말을 멈추더니, 창밖의 '속삭이는 숲' 쪽을 보며 순간 어두운 표정을 짓다가 이내 다시 미소 짓습니다."

### [흐름 2] 자연어 기반 의도 감지 및 제어권 이양

1.  **Player Action**: (힌트를 바탕으로) "혹시 숲을 보며 걱정하는 일이 있나요? 표정이 안 좋아 보였어요."
2.  **`⚙️ 오케스트레이터 (LLM)`**:
    *   **Input**: 플레이어의 자연어 입력.
    *   **LLM Process**:
        1.  단순 키워드 매칭을 넘어, 문장의 뉘앙스를 분석합니다. "걱정", "표정이 안 좋아 보였다" 등의 표현을 통해, 이것이 단순 정보 요청이 아닌 **'상대방의 내면을 살피려는 공감/통찰 시도'**임을 높은 확률로 추론합니다.
        2.  이를 **'암묵적 스킬 사용 의도(Implicit Skill Use Intent)'**로 판단하고, `관계 마스터`에게 제어권을 넘기는 것이 최선이라고 결정합니다.
    *   **Output**: `관계 마스터`를 활성화하고, 심층 분석에 필요한 컨텍스트를 전달합니다.
        ```json
        {
          "handoff_reason": "implicit_insight_check",
          "target_npc_id": "holly_baker",
          "topic": "whispering_woods"
        }
        ```

### [흐름 3] 다차원적 관계 상태와 LLM의 심층 대화

1.  **`🤝 관계 마스터 (LLM)`**:
    *   **Input**: 제어권과 컨텍스트, 그리고 `데이터 저장소`에서 조회한 홀리의 현재 `RelationshipState` 데이터를 받습니다.
        ```json
        /* 홀리와 플레이어의 현재 관계 상태 */
        {
          "vectors": {
            "trust": 5, // 일반적인 신뢰도
            "empathy": 2, // 개인적인 유대감, 공감대
            "respect": 8 // 모험가로서의 존중
          },
          "known_topics": ["bakery", "town_gossip"],
          "emotional_state": "guarded" // 현재 감정 상태
        }
        ```
    *   **LLM Process**:
        1.  `empathy` 수치가 아직 낮고(`2`), `emotional_state`가 '경계 중'이므로, 지금 바로 비밀을 털어놓는 것은 부자연스럽다고 판단합니다.
        2.  플레이어의 '공감 시도'에 긍정적으로 반응하면서도, 한 걸음 물러서는 대화를 생성합니다.
    *   **Output (to Player)**: "홀리는 당신의 질문에 잠시 망설이는 듯합니다. '아니에요, 그냥... 예전에 안 좋은 기억이 있어서요.' 그녀는 화제를 돌리려는 듯 보이지만, 당신의 배려 깊은 질문에 그녀의 눈빛이 미세하게 흔들리는 것을 느낍니다."
        *   **핵심:** 이 묘사 자체가 '실패가 아닌 작은 진전'이라는 피드백을 플레이어에게 줍니다.

### [흐름 4] '실패를 통한 전진'과 데이터 기반 상태 변화

1.  **Player Action**: "강요할 생각은 없었어요. 혹시 들어줄 사람이 필요하면 언제든 찾아와요."
2.  **`🤝 관계 마스터 (LLM)`**:
    *   **Input**: 플레이어의 공감적인 후속 행동.
    *   **LLM Process**:
        1.  플레이어가 압박하지 않고 공감대를 형성하려 한다고 판단합니다. 이는 '실패'가 아니라, 관계 발전을 위한 성공적인 '다른 경로'입니다.
        2.  이 행동이 `empathy` 벡터를 크게 증가시킬만한 행동이라고 판단합니다.
    *   **Output (to `데이터 저장소`)**: `RelationshipState` 데이터의 업데이트를 요청하는 MCP를 호출합니다.
        `update_relationship_state("holly_baker", {"vectors": {"empathy": {"operation": "add", "value": 3}}})`
        *   이제 `empathy`는 5가 되었고, 이는 다음 대화에서 홀리가 마음을 열 수 있는 임계점을 넘었다는 것을 의미합니다. 이처럼, 스킬 체크의 성공/실패가 아닌, **대화의 과정 자체가 관계 데이터를 변화시킵니다.**

---

### [흐름 5] 개인 퀘스트의 자연스러운 발생

1.  **Player Action**: (며칠 뒤) "홀리, 지난번에 말했던 안 좋은 기억에 대해 혹시 이야기해 줄 수 있나요?"
2.  **`🤝 관계 마스터 (LLM)`**:
    *   **Input**: 플레이어의 요청 및 업데이트된 `RelationshipState` (`empathy`가 5인 상태).
    *   **LLM Process**:
        1.  `empathy` 수치가 비밀을 공유할 만큼 충분히 높다고 판단합니다.
        2.  `서사 엔진`에 `generate_quest(hook_id: "holly_brother_story")`를 요청하여 개인 퀘스트의 핵심 내용을 받습니다.
        3.  받은 퀘스트 내용을 홀리의 감정이 듬뿍 담긴, 감동적인 대화로 각색하여 생성합니다.
    *   **Output (to Player)**: "당신은... 어떻게... 맞아요. 몇 년 전에 제 오빠가 그 숲에 들어갔다가... 돌아오지 않았어요. ...염치없지만, 당신이라면 혹시..." 라는 대사와 함께 개인 퀘스트가 자연스럽게 플레이어에게 전달됩니다.
